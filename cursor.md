- Prefer small, focused file changes over large rewrites.

- Runtime: Node.js
- Language: TypeScript (strict; no new `.js` / `.jsx` app files)
- Framework: Next.js (App Router)
- UI: React with TypeScript (`.tsx`)
- Package manager: npm unless the repo already has another lockfile

Keep new code aligned with this stack. Prefer Next.js conventions (App Router, Server Components by default, client components only when needed).

## Conventions

- Keep functions and components small and readable.
- Handle errors instead of swallowing them.
