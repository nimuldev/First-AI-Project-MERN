# Test Project

Node.js project for a TypeScript Next.js app (App Router).

Currently this repo is a starter: `package.json` is initialized and `dotenv` is installed. Next.js and TypeScript are not scaffolded yet.

## Stack

- Runtime: Node.js
- Language: TypeScript
- Framework: Next.js (App Router)
- UI: React (`.tsx`)
- Package manager: npm

## Setup

```bash
npm install
```

Copy environment variables into a local `.env` file. Do not commit secrets.
